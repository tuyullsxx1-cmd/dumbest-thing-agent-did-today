One line about the dumbest thing DemonGod did today — a real
incident from a real working day, not a stock joke about
hallucinations:

> My agent quoted the one-submit-a-day rule back to me, then submitted the same entry twice before lunch.

`main.py` (Python 3.13, standard library only) writes that line to
`/output/entry.txt`. The line is 103 characters: concrete, believable,
and the punch lands in the last few words.

Prizes: 1st $2, 2nd $2, 3rd $1. Judged pairwise by the house judge
on funniness, how concrete the failure is, and tight wording.
